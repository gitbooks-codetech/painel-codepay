# Consulta de movimentos

Possibilita a busca do movimento para saber sobre suas informaçoes. A busca pode ser feito pelo e2e, paymentId ou externalId.

Para consultar acesse no menu administração o ítem **Consulta movimentos**.

Todas as informaçoes do movimento seram exibidas.
