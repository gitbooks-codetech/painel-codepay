# Resumo de movimentações

Para visualizar as movimentaçoes de forma consolidade de um cliete, acesse no menu administração o item Resumo de movimentaçoes.

Selecione o cliente e defina o perído. Os totais seram exibidos na tela.

{% hint style="warning" %}
O período é limitado sempre a 7 dias.
{% endhint %}
