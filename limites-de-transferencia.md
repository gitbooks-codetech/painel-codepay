# Limites de Transferência

Possibilita criar limites para a movimentação da conta de cada cliente.

{% hint style="info" %}
Ao criar a conta do cliente os limites são todos igual a zero, isso significa que no caso a conta não possui limite definido mas o cliete consegue movimentar a conta sem um limite definido.
{% endhint %}

O cliente pode enviar uma solicitação de limite para ser aprovada ou podemos criar diretamente para o cliente.

Para acessar clique em administração e selecione limites de transferência.\
Os filtros aceitam busca pelo clientId, nome e o status da solicitação de limite de transferência.

<figure><img src=".gitbook/assets/image (2) (1).png" alt=""><figcaption></figcaption></figure>

### Criar Limite

Clique no botão <mark style="color:green;">**Gerar limite para cliente**</mark> e preencha os campos. Informe o seu código de segurança (2fa) e clique em Cadastrar. O limite já está ativo.&#x20;

{% hint style="warning" %}
É possível gerar o limite com status de pendente caso ainda não tenha certeza, mas para o limite já ser válido ao criar utilize o status **Ativo**.
{% endhint %}

<figure><img src=".gitbook/assets/image (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

### Editar o status do limite

O cliente, ao enviar uma solicitação de limite, essa fica com o status Pendente, para aceitar ou alterar os limites clique no ícone de edição para alterar além do status as demais informaçoes.
